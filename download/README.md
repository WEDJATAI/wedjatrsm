# RSM Platform — Database Package

Complete, verified database deliverable for **Lilo Cafe and Restaurant** (RSM —
Restaurant System Management, Next.js 16 + Prisma + SQLite). Generated by the
Round 10 provisioning audit (`bun scripts/round10-provision.ts`).

## Files

| File | Description |
| --- | --- |
| `rsm-platform-database.db` | The complete platform database (single embedded SQLite file — this is the ONLY database the platform needs; no external DB server is required). All schema modifications from every build round (R3 → R10) are applied. |
| `rsm-database-manifest.json` | Machine-readable audit manifest: SHA-256 checksums, row counts for all 25 tables, operational snapshot, vision-subsystem state, compliance checks. |

## Verification (all PASS)

- `PRAGMA integrity_check` → **ok**
- `PRAGMA foreign_key_check` → **0 violations**
- Table inventory → **25/25** tables present (matches `prisma/schema.prisma`)
- `prisma db push` → *"The database is already in sync with the Prisma schema"*
- Passwords stored as bcrypt hashes only; camera stream URLs contain **no credentials**
- Every applied AI table-movement has a named human decider in the audit log (0 auto-applied)

## What's inside

- **Operations**: 3 users (admin / waiter / kitchen), 5 floor plans, 15 tables,
  39 products (20 sellable + 19 ingredients), 7 modifier groups, 38 recipe BOM lines,
  117 orders (64 paid · EGP 29,402.76 historical revenue), 71 payments, inventory ledger.
- **AI Vision / CCTV (R9)**: 2 online cameras (CAM-001 Main Hall, CAM-002 Terrace),
  6 polygon zones mapped to dining tables, 86 processed edge events
  (74 applied · duplicates/stale/low-confidence/cooldown correctly filtered),
  20 movement candidates (6 confirmed, 10 rejected, 4 conflict — **0 pending**),
  236 audit-log rows (122 vision-related), ingest key + tunable detection config.

## Restoring

```bash
cp rsm-platform-database.db /path/to/project/db/custom.db
```

The app reads the DB location from `DATABASE_URL` (`file:…/db/custom.db`).

**Fresh-install alternative:** `bun prisma/seed.ts` (users/menu/floors/orders) then
POST `/api/vision/simulate { "action": "setup_demo" }` (cameras + zones).
